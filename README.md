# 말랑 연구소 (squishy-lab)

손끝으로 누르고 당기는 웹 말랑이 장난감 두 개입니다. 빌드 없이 HTML 파일 하나씩으로 돌아가고, 브라우저에서 바로 열립니다.

| 앱 | 한 줄 소개 | 주소 |
|---|---|---|
| 첫 화면 | 두 앱으로 가는 입구 | https://magic3ightball.github.io/squishy-lab/ |
| 나이스 큐브 (`nice-cube/`) | 바닥에 놓인 말랑이 큐브를 마우스·트랙패드·터치로 만짐 | https://magic3ightball.github.io/squishy-lab/nice-cube/ |
| 공중 말랑이 (`air-squishy/`) | 웹캠 손 추적으로 허공에 뜬 말랑이를 만짐 | https://magic3ightball.github.io/squishy-lab/air-squishy/ |

## 나이스 큐브

바닥에 놓인 3D 말랑이 큐브입니다.

- **누르기 / 당기기 / 바풍**: 아래 패널에서 만지는 방식을 고릅니다. 바풍(공기 풍선)은 질감이 물슬라임일 때 나타나고, 누르고 있으면 풍선이 부풀고 부푼 풍선을 누르면 터집니다.
- **질감**: 젤리 → 유리 → 푸딩 → 물슬라임 순서로 바뀝니다.
- **꾸미기**: 색상, 반짝이, 로고(양각·음각·없음, 글씨 바꾸기), 쫀득함(복원 속도), 누르는 힘.
- **소리**: 질척 → 톡 → 끔. 처음 만질 때 소리가 켜집니다.

| 입력 | 동작 |
|---|---|
| 마우스 | 큐브를 클릭해 누르거나 당김. 빈 곳을 끌면 큐브를 돌려 봄 |
| 트랙패드 | 클릭·끌기는 마우스와 같음. 두 손가락을 벌리면 늘어나고 모으면 눌림 |
| 아이폰·터치 | 한 손가락으로 누르기·당기기. 두 손가락을 벌리면 늘어나고 모으면 눌림 |

## 공중 말랑이

웹캠으로 손을 인식해(MediaPipe Hand Landmarker) 허공에 떠 있는 말랑이를 직접 만지는 버전입니다. 카메라 영상은 기기 안에서만 처리되고, 손 인식 모델 파일만 Hugging Face에서 내려받습니다.

시작 화면에서 **카메라로 시작 / 데모 보기 / 마우스·트랙패드로** 중 하나를 고릅니다.

| 손동작 | 동작 |
|---|---|
| 👆 손가락으로 찌르기 | 손가락 끝이 닿은 자리가 들어감. 카메라 쪽으로 손을 뻗을수록 깊이 눌림 |
| ✋ 손바닥으로 누르기 | 손가락을 펴고 손바닥째 밀면 넓게 눌림 |
| 🤏 집어서 당기기 | 큐브 가장자리 근처에서 엄지·검지 끝을 붙이면 집힘. 움직이면 늘어나고, 손가락을 벌리면 놓임 |
| 🙌 두 손으로 늘리기 | 양손으로 양쪽 가장자리를 집고 벌림 |
| 📏 거리 기준 | 처음 손을 보여 준 거리가 '큐브 바로 앞'. 어긋나면 설정 → 기준 다시 잡기 |

| 마우스·트랙패드 모드 | 동작 |
|---|---|
| 클릭한 채로 두기 | 눌림 |
| 클릭한 채 끌기 | 늘어남 |
| 트랙패드 두 손가락 벌리기 / 모으기 | 양쪽으로 늘어남 / 눌림 |

- 손 전체가 화면에 들어오고, 손바닥이나 손등이 카메라를 향해야 인식이 잘 됩니다.
- 카메라는 **https 또는 localhost**에서만 켜집니다. 파일을 더블클릭해서(`file://`) 열면 카메라가 동작하지 않습니다.
- 개발자 모드(설정 → 개발자 모드, 또는 주소 뒤에 `?dev`)에서 개선 항목 A1~A4를 켜고 끄며 비교하고, 손 움직임을 녹화·재생할 수 있습니다.
  - A1 안정화 · A2 깊이 곡선 · A3 닿은 자리 · A4 당김 긴장

## 로컬에서 실행

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000/ 을 엽니다. three.js, MediaPipe, 손 인식 모델, 글꼴을 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 스모크 테스트

세 페이지가 콘솔 에러 없이 열리고 WebGL 캔버스가 그려지는지 데스크톱 크롬과 아이폰 13 화면에서 확인합니다. 테스트할 때만 Node가 필요합니다.

```bash
npm install
npx playwright install chromium
npm test
```

스크린샷은 `test-results/` 아래에 저장됩니다. 아이폰 13 항목은 크로뮴으로 화면 크기와 터치만 흉내 낸 것이므로, 사파리 고유 동작은 실제 아이폰에서 따로 확인해야 합니다.

## 배포

`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/pages.yml`)가 `index.html`, `nice-cube/`, `air-squishy/`만 GitHub Pages에 올립니다. 빌드 단계는 없습니다.
